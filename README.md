# 🎮 Escrevendo as Classes de um Jogo

Projeto desenvolvido como parte de um desafio da DIO.

## 📌 Sobre o projeto

O projeto consiste na criação de uma classe genérica para representar um herói de uma aventura.

Cada herói possui:

- Nome
- Idade
- Tipo

O herói também possui um método `atacar()`, que apresenta uma mensagem diferente de acordo com seu tipo.

## ⚔️ Tipos de heróis

| Tipo | Ataque |
|---|---|
| Mago | Magia |
| Guerreiro | Espada |
| Monge | Artes marciais |
| Ninja | Shuriken |
